# Tripleten web_project_around_express

# Descripcion del proyecto

Es una API para crear post (card) con un nombre, imagen y propiertario.
La post tiene la funcionalidad para dar like y dislike a una card que se le haya hecho like

Igual se puede crear usuario con un nombre, descripcion sobre el y un avatar de perfil.
Por el momento no cuenta con autentificacion sino hardcoding el id del primer usuario creado para utilizar ese id

Estamos utilizando controlador-modelo-ruta para crea la API

# Tecnologias usadas

-- MongoDB
-- JavaScrip
-- NodeJS
-- ExpressJS
-- EslintJS
-- Airbnb
-- Mongoose

# Pasos de la instalacion de la "Web_projects_around_express"

1. Clone el respositorio

```bash
git clone https://github.com/LuisArielRetanaHernadez/web_project_around_express.git
```

2. Instale las independencias de la APP

```bash
npm install
```

O puede ejecutar el comando "npm i" que es similar al anterior "npm install"

```bash
npm i
```

3. Para ejecutar la APP en desarrollo tiene que ejecutar el comando:

```bash
npm run start:dev
```

4. Para ejecutar la APP en producion tiene que ejecutar el comando:

```bash
npm run start
```
